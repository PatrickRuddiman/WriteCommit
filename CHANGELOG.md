# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2025-01-03

### Added
- Initial TypeScript implementation
- CLI tool for generating AI-powered commit messages
- VSCode extension with native integration
- GitHub Copilot support via VSCode Language Model API
- OpenAI API integration
- Semantic diff analysis and chunking
- Configurable AI parameters (temperature, top-p, etc.)
- Interactive setup wizard
- Dry-run mode for previewing commit messages
- Verbose logging option

### Features
- Cross-platform support (Windows, macOS, Linux)
- Smart diff chunking for large changes
- Context-aware commit message generation
- Pattern-based prompt system
- Configuration file support
- Environment variable support
- API key sanitization (trim whitespace)

### Documentation
- Comprehensive README with usage examples
- TypeScript conversion documentation
- Setup and configuration guides
